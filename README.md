# DevMind
# 🎯 최종 컨셉 (확정 버전)

> “개발자를 위한 AI 기반 지식 추천 플랫폼”
> 
> 
> 외부 개발 블로그/문서 정보를 자동 수집하고,
> 
> 사용자가 작성한 노트와 태그 기반으로 **맞춤형 지식 추천 + 요약 + 자동 태깅**을 제공하는 웹 서비스.
> 

이 컨셉은

**벨로그 + 노션 + AI 추천 + 개발 블로그 크롤링**

을 합친 형태라서

“AI + 웹 + 정보통합”이라는 **성균관대 소프트융합대학의 핵심 키워드**와 완벽하게 맞아떨어져.

---

# 💡 핵심 기능 4가지 (최대한 단순화 + 강력함)

## 1) **개발 블로그·문서 크롤링 기능 (외부 정보 수집)**

- 크롤링 대상:
    - Velog 인기글
    - Medium 특정 태그
    - GitHub Trending READMEs
    - StackOverflow Top QnA (정적 크롤링)
- 크롤링한 데이터를
    - 제목
    - 핵심 요약(AI)
    - 태그(AI)
        
        으로 정제하여 저장.
        

→ **초기 사용자 없어도 풍부한 콘텐츠 확보 가능**

→ 추천 알고리즘 시드(seed) 데이터 확보 가능

---

## 2) **AI 기반 자동 태그 생성 (사용자 노트 + 크롤링 글 모두)**

- 사용자가 노트 작성 시 자동 태그 생성
- 크롤링한 글도 title+본문을 기반으로 자동 태그 생성

→ 태그라는 공통 구조가 생겨서

→ 추천 알고리즘이 “초기 데이터 없음 문제” 완벽 해결됨

---

## 3) **태그 기반 추천 기능 (크롤링 + 사용자 노트 모두 대상)**

노트 상세페이지에서

→ **공통 태그 기반 BEST 5 추천**

- 크롤링한 글
- 사용자 본인 노트
    
    둘 다 포함됨.
    

예시:

사용자 노트 태그: `Spring, JPA, Transaction`

추천:

- 크롤링된 Velog 글 "Spring Transaction 완전 정리"
- GitHub trending “Spring Boot Example Repo”
- 본인이 예전에 노트한 “JPA Flush 이해하기”

→ **시작부터 풍부한 추천 가능**

→ 개인화 + 정보통합 기능 모두 충족

---

## 4) **AI 기반 요약 기능**

- 사용자 노트 3줄 요약
- 크롤링 블로그 요약
- GitHub README 핵심 요약

→ AI 기반 정보 압축 기능

→ 서비스의 지능형 요소 핵심
